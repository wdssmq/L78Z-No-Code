## py-exif-tool


## 使用

### 环境及依赖

可能并没有具体 Python 版本要求？

```bash
# 脚本所在目录
python3 -m venv .venv

# 激活虚拟环境 - Git Bash 或类 Unix shell
source .venv/Scripts/activate

# 或者用 Windows 命令行
.venv\Scripts\activate

# 依赖
.venv/Scripts/pip install -r requirements.txt
# .venv/Scripts/pip freeze > requirements.txt   # 记录当前依赖

```

### 运行

```bash

.venv/Scripts/python run.py name.png


```
