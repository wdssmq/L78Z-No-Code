# 将网址保存至 *.url 文件

## 直接上演示吧

示例数据，在脚本目录内创建`input.txt`并写入；

<!--more-->

```conf
https://www.bilibili.com/video/BV1qe4y1d7ZM
https://www.bilibili.com/video/BV1mv4y1u79j
https://www.bilibili.com/video/BV1iv4y1K7iy
```

执行`main.py`;

执行结果；

```bash
/output
# BV1iv4y1K7iy.url
# BV1mv4y1u79j.url
# BV1qe4y1d7ZM.url
```
